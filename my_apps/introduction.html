Hardware Control

CPU plans the drink; MCU makes the machine respond instantly.

CPU

Main brain for UI display, online payments, and AI algorithm interface.

MCU

Small brain for fast sensor readings, pump switches, heater logic, and motor control.

RAM

Temporary working space so machine information appears smoothly without freezing.

Grinding motor controls bean amount by timing.

Peristaltic pumps move water, milk, and syrup accurately.

Stepper motor releases one cup and positions it safely.

Temperature and load-cell feedback keep drinks consistent.

AI Selection

The AI value is backstage: fewer stockouts and earlier repairs.

Inventory Forecasting

Load cells track remaining raw materials. AI predicts consumption rate and sends a restock notice before ingredients run out.

Predictive Maintenance

Vibration and current signals help detect abnormal pump behavior before complete mechanical failure.

If bubbles are predicted to run out within two hours, the system can update the UI and remove affected drinks from the menu.

If the pump is likely to fail within 48 hours, the system can reduce operating frequency and send a replacement reminder.

Transport Protocols

TCP protects payments; UDP keeps screen media smooth.

TCP

Best for credit card and e-wallet payment data because accuracy, ordering, ACK packets, and retransmission matter more than speed.

UDP

Best for live video advertisements because low latency and continuity matter more than perfect frame delivery.

The system is not a single-protocol design. It chooses the protocol based on the risk and timing need of each data type.

Database Logic

The database decides whether the machine should accept the order.

1. Pre-purchase

Check recipes, ingredients, and supplies before payment.

2. Purchase

Payment time limit, proof-of-purchase identifier, transaction record.

3. Post-purchase

Fetch recipe, update stock, sync server, hide unavailable drinks.

Local database and online server work together to keep recipes, stock, machine health, and restock signals current.
